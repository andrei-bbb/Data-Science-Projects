Salisfort Motors HR Analytics
Overview

This project analyzes the Salisfort Motors HR dataset from Kaggle to uncover key insights and build a predictive model for employee attrition. The entire process, including data exploration, feature engineering, and model building, is documented in a Jupyter Notebook.
Key Files

    Salisfort project.ipynb – Full data analysis and model development workflow.
    English - Executive Summary.pdf – Short, actionable report summarizing key findings and recommendations.

Methodology

    Exploratory Data Analysis (EDA) to identify trends and patterns.
    Feature Engineering & Model Selection for employee attrition prediction.
    Data Visualization to effectively communicate insights.

Tools & Libraries

    Python (Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn)
    Jupyter Notebook

Background

This project was completed after earning the Google Advanced Data Analytics Certificate and studying Storytelling with Data by Cole Nussbaumer Knaflic, applying best practices in data-driven decision-making.
